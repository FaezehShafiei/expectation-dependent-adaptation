# prefrontal-feedback-adaptation

Analysis code for:

Shafiei F, Zare M, Shakerian F, Arabzadeh E, Dehaqani M-RA.
*Prefrontal feedback gates expectation-dependent adaptation in inferotemporal cortex.*

## Requirements
- MATLAB R2022a
- Statistics and Machine Learning Toolbox
- SHINE toolbox (stimulus luminance/contrast equalization)

## Contents
- `Fig1_ResponseCharacteristics/` – category selectivity of IT and vlPFC neurons
- `Fig2_RSA/` – representational similarity and partial RSA
- `Fig3_AdaptationIndex/` – early/late adaptation indices and block effects
- `Fig4_SSA_Reversal/` – expectation-dependent SSA in single units and LFPs
- `Fig5_GrangerCausality/` – trial-wise Granger causality and GI-split analyses
